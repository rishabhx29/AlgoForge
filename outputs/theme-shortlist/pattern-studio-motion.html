Cell fill · 200ms

The solved cells fade and un-squeeze in sequence along the row, 14ms apart. It reads as your progress laying down, then stops. scaleY(.4) → 1 plus opacity — transform only, so no layout cost.

Figure count-up · rAF

The headline number climbs to its real value with an ease-out cubic. Under reduced motion it snaps straight to the final value — the figure is never withheld, only animated.

Progress draw · 700ms

The rule grows from zero once on mount. It is the only element that animates a length, and it does so once — never on scroll, never on re-render.

Row reveal · 140ms

Hovering a row lifts the next unsolved problem into view. This one is functional: the sheet stays scannable, but answers "what would I actually do here?" without a click.

Why the motion is restrained: you use this page every day. Anything that animates on every visit becomes a delay you learn to resent. So the motion is limited to the moments that carry information — progress arriving, a figure changing, a row explaining itself — and everything else is instant. With animation fully disabled the interface still reads correctly, which is the test it has to pass.
