Inside this chapter concept

Questline explores a more structured way to navigate AlgoForge. This is a design proposal, not an implemented learning system.

  • Reused foundations: existing DSA topics, problems and learner progress, presented here with sample data.
  • Proposed new features: skill-tree dependencies, chapter unlock logic and chapter milestone badges.
  • Recommended sequence: the connectors suggest a learning order; they do not establish formal prerequisites. Arrays branches into Hash maps and Two pointers; Two pointers leads into Sliding window.

No chapter unlocks, XP awards, backend calls or persistence run in this concept. The navigation labels are static; this dialog is the only interaction.
